# WeatherNow — Vanilla JS Weather Dashboard

A weather dashboard built with plain HTML, CSS, and JavaScript. No frameworks,
no build step, no API key required — uses the free Open-Meteo API.

## Features
- Search weather by city name (geocoding + forecast API calls)
- "Use my location" via the Geolocation API
- 5-day forecast grid
- Async/await, fetch, error handling, and DOM manipulation from scratch

## Run locally
Just open `index.html` in a browser, or serve it:
```bash
npx serve .
```

## Tech
HTML5 · CSS3 · JavaScript (ES2020+) · Open-Meteo REST API
